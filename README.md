## Description
Our game is a first person horror game. You go around a dark map looking for clues, and there's a monster following you the whole time. The more clues you find, the faster and more aggressive it gets. If it catches you, you lose. Find all the clues and you can escape.

Right now we're planning on one map, a flashlight, the monster, and some kind of clue system. This could change as we go.
